# Projects plugin

Install Projects from Plugins. In AI Chat, Projects appears above Chat history in the chat sidebar. Use the small plus beside Projects to create a project with a name and one or more source folders chosen through the native folder picker. There is no separate Projects page or main navigation item.

Click a folder row to expand or collapse its chats. Hover or focus a row to reveal its new-chat plus and settings menu. Each project has independent conversations; ordinary chats remain under Chat history. Search filters chat titles. Project settings retain shared instructions without leaving the chat screen.

New projects store instructions and chats in `<first-source-folder>/.powerbrix/projects/<project-id>.json`. The private application profile contains a locator for each folder-backed project. Attach or remove folders in the project settings popup. The first folder is marked Project location; if you remove it, the state moves to the next folder while preserving chats and instructions. Documents are not moved. Existing projects made before folder selection remain readable. Replacing/updating the app preserves project data.

Before each project reply, the app scans supported source documents recursively across all attached folders, reuses extracted text only when the file's modification/change times and size match, and selects excerpts relevant to the question. Added, edited and deleted files are reflected on subsequent requests. Files stay in their original folders. Overlapping source folders do not duplicate documents. Hidden files, symlinks, dependency folders and common build directories are excluded. Supported files include PDF, Word (.docx), Markdown and the same text/code formats as attachments. There is no external indexing or inference API.

Per-file limits are 12 MB and 2,000,000 extracted characters. The model receives relevant excerpts within its context budget, not the entire folder in every prompt. Unreadable files are identified to the model so it can explain missing material. Large directory scans stop with a clear error rather than silently claiming a complete scan. Scanned PDFs need OCR to provide readable text. Project instructions support 12,000 characters, but the chosen model's context window may require shorter instructions.

Each project supports 200 chats with up to 100 recent messages saved per conversation. Other project chats are not automatically merged into a prompt. Removing a project deletes its own PowerBrix state, not documents in the source folder.

Validation covers folder-backed storage, multiple roots, primary-folder changes, source-file changes, project isolation, permissions, restart persistence, collapsed chat lists, creation and settings dialogs, normal chat regression tests and actual local inference using project instructions and a source document.

Drag an existing conversation onto a project row to move it into that project, or onto the Chats section to move it back to ordinary chats. Project-to-project moves are supported too. Drop targets highlight, and collapsed projects expand while hovering with a dragged chat. The conversation keeps its ID, messages, reasoning, usage data and title. Future replies use the destination project context; returning to Chats removes that project context. Moves are disabled while generating a reply. The destination is saved before removing the source, with rollback handling for failed project writes.
